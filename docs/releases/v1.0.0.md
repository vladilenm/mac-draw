# Mac Draw 1.0.0

Первая публичная версия бесплатного приложения для рисования поверх экрана Mac. Подходит для обучающих видео, разбора кода и демонстраций на созвонах.

## Скачать и установить

1. Скачайте **MacDraw-universal.zip** ниже. Архивы GitHub **Source code** предназначены для разработчиков.
2. Распакуйте архив и перетащите **Mac Draw.app** в **«Программы»**.
3. Откройте приложение. Если macOS блокирует запуск, после первой попытки разрешите его в **«Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть»**. Подробности находятся в `INSTALL.txt` внутри архива и в [README](https://github.com/vladilenm/mac-draw#установка).

Нужны **macOS 14+** и Mac на **Apple Silicon или Intel**. Xcode для установки не нужен.

**Сборка имеет ad-hoc подпись, но не подписана Developer ID и не заверена Apple.** Обычное открытие без дополнительного подтверждения на другом Mac не гарантируется. Инструкция описывает исключение для конкретного приложения.

## Возможности

- Перо, стрелки, линии, прямоугольники, овалы, текст и ластик.
- Шесть цветов, три толщины, отмена и повтор.
- Прозрачный холст, передвигаемая панель и режим курсора.
- **⌃⌥D** — показать/скрыть рисунки с сохранением; **Esc** — очистить и скрыть.
- Работа локально, без аккаунта, аналитики и сетевых запросов. Лицензия MIT.

Для записи выбирайте захват **всего дисплея**. Рисунки хранятся только в текущем сеансе; экспорта и автообновлений пока нет.

Ручная проверка интерфейса проведена на Apple Silicon с macOS 15.7.7. Intel-интерфейс, установка на чистом другом Mac, несколько дисплеев и полноэкранные Spaces отдельно не подтверждены. [Состояние проверок](https://github.com/vladilenm/mac-draw/blob/v1.0.0/docs/VERIFICATION.md).

`SHA256SUMS.txt` содержит контрольные суммы архива и инструкции. [Сообщить об ошибке](https://github.com/vladilenm/mac-draw/issues/new/choose).
