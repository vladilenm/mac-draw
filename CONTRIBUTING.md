# Участие в Mac Draw

Спасибо за помощь. Проект небольшой: полезны и исправления кода, и подробные сообщения о том, что не работает на вашем Mac.

## Сообщить об ошибке

Создайте [issue](https://github.com/vladilenm/mac-draw/issues/new/choose). Укажите:

- версию macOS, Intel или Apple Silicon и версию Mac Draw;
- шаги, после которых возникает проблема;
- что ожидалось и что произошло;
- число дисплеев и программу записи, если проблема связана с ними.

Короткое видео помогает воспроизвести проблему. Перед публикацией уберите из него личные данные.

## Изменить код

Нужны macOS 14+ и Swift 6.0+ из Xcode или Command Line Tools. Сторонних пакетов нет.

```sh
git clone https://github.com/vladilenm/mac-draw.git
cd mac-draw
./scripts/test.sh
./scripts/build.sh
open "build/Mac Draw.app"
```

Для своего pull request сделайте fork репозитория и отдельную ветку. Опишите проблему, новое поведение и выполненные проверки. Для исправления ошибки добавьте проверку, которая ловит именно эту ошибку, если это можно сделать без управления чужими окнами.

- `Sources/DrawingCore` — геометрия, hit testing и история действий.
- `Sources/MacDraw` — AppKit-холст, окна, SwiftUI-панель и сочетания клавиш.
- `Tests/DrawingCoreTests` — проверки без зависимости от XCTest.
- `scripts` — сборка, тесты, иконка и упаковка релиза.

Изменения интерфейса проверяйте вручную: выбор другого инструмента после рисования, ввод текста, Esc, отмена, режим курсора и возврат к приложению под холстом. Полный список — в [VERIFICATION.md](docs/VERIFICATION.md).

Не добавляйте в pull request каталоги `.build`, `build` или `dist`. Если меняются клавиши, установка или ограничения, обновите README и `Resources/INSTALL.txt`.
